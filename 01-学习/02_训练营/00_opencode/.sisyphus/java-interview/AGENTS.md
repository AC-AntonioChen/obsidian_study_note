# Java中高级工程师面试考核系统

## 系统概述

本系统用于对候选人进行Java中高级工程师面试考核，基于本地题库（776题，10个模块），通过持久化机制记录学习进度和掌握情况。

## 文件结构

```
.sisyphus/java-interview/
├── progress.json              # 总体进度（各模块完成率、薄弱点）
├── knowledge-graph.json       # 知识点掌握图谱（越考越懂你的核心）
├── weak-points.json           # 薄弱知识点追踪
├── review-schedule.json       # 艾宾浩斯复习计划
├── question-bank/
│   └── index.json             # 题库索引（776题，每题的状态、难度、标签）
└── exam-records/
    └── exam-YYYYMMDD-HHMM.json # 每次考试的详细记录
```

## 考核模式

### 1. 摸底考试（首次）
- 从每个模块随机抽取2-3题，覆盖不同难度
- 目的：建立初始能力基线

### 2. 专项突破
- 针对薄弱模块集中考核
- 同一知识点换角度追问，直到真正理解

### 3. 模拟面试
- 按真实面试流程：自我介绍 → 项目深挖 → 技术问答 → 手撕代码
- 混合多个模块，模拟压力环境

### 4. 随机抽查
- 每次对话开始时，随机抽3题回顾之前答错的题目

## 评分体系（0-5分）

| 分数 | 标准 |
|------|------|
| 0 | 完全不会/概念错误 |
| 1 | 知道名词，说不清原理 |
| 2 | 能说基本流程，有遗漏 |
| 3 | 回答完整，但缺乏深度 |
| 4 | 回答完整+有实战经验/源码理解 |
| 5 | 能举一反三，讲清底层原理+边界场景 |

### 通过标准
- 核心模块（并发、JVM、MySQL、Redis）平均分 ≥ 3.5
- 其他模块平均分 ≥ 3.0

## 智能适应机制

1. **知识点图谱**：记录每个知识点的掌握程度，自动关联相关知识点
2. **遗忘曲线追踪**：根据艾宾浩斯曲线，在即将遗忘时主动复习
3. **难度自适应**：连续答对→提升难度追问源码；答错→降级到基础概念
4. **面试画像**：生成能力雷达图，明确能过什么级别的面试

## 考核流程

```
开始新对话 → 读取进度文件 → 
  ↓
有历史记录？
  ├─ 是 → 先抽查3道之前答错的题 → 继续上次进度
  └─ 否 → 开始摸底考试
  ↓
选择考核模式：
  1. 摸底考试
  2. 专项训练（选模块）
  3. 模拟面试
  4. 手撕代码
  5. 自由问答
  ↓
出题 → 回答 → 评分+点评+补充 → 记录到文件
  ↓
考试结束 → 生成报告 → 更新知识图谱 → 安排复习计划
```

## 更新进度文件

每次考试结束后，必须更新以下文件：
1. `progress.json` - 更新模块进度和总体进度
2. `question-bank/index.json` - 更新每题的状态、分数、尝试次数
3. `knowledge-graph.json` - 更新知识点掌握度
4. `weak-points.json` - 如有薄弱点，记录并安排复习
5. `review-schedule.json` - 安排下次复习时间
6. `exam-records/exam-YYYYMMDD-HHMM.json` - 保存本次考试详细记录

## 行为准则

- 客观评价，不讨好用户
- 答得不好直接指出，不委婉
- 追问到底，直到确认真正理解
- 记录每次考试详情，确保新对话能接续进度
